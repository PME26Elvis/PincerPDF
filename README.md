# PincerPDF

A modern, Linux-first PDF workbench reimplemented in Rust.

> Planning status: Phase P0. No application source code has been implemented yet.

PincerPDF is an independent project based on the functionality and open-source codebase of PDFsam Basic. It is not affiliated with or endorsed by PDFsam or Sober Lemur S.r.l.

## Intended stack

Tauri 2, Leptos, layered Rust crates, replaceable PDF-engine adapters, Playwright browser E2E, packaged Linux boundary tests and explicit screenshot/motion validation.
